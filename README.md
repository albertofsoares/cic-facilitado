Este projeto é uma Single Page Application (SPA) moderna, desenvolvida para atuar como um portal de aprendizado de tecnologia. O sistema é totalmente funcional, integrando persistência de dados em tempo real e um sistema de gerenciamento de conteúdo completo em uma única página.

O projeto foi desenvolvido por mim com a colaboração integral da inteligência artificial Gemini Pro, resultando em uma interface fluida, responsiva e altamente interativa.

🛠️ Tecnologias Utilizadas
HTML5 & JavaScript (ES6+): Estrutura e lógica do sistema.

Tailwind CSS: Framework utilitário para estilização e design responsivo.

Firebase (Google):

Firestore: Banco de dados NoSQL para posts, categorias e quizzes.

Authentication: Gestão de acesso e perfis de usuário.

Font Awesome: Biblioteca de ícones.

Google Fonts: Tipografia focada em legibilidade (Inter e JetBrains Mono).

✨ Funcionalidades Principais
🌓 Sistema de Temas: Suporte a modo claro e escuro (Dark/Light Mode) com detecção automática de preferência do sistema.

📊 Barra de Progresso Real-Time: Acompanhamento visual da leitura de conteúdos, salvo individualmente por usuário.

📝 Markdown Renderer: Processador interno que transforma texto puro em conteúdo formatado para artigos técnicos.

🧠 Área de Treino (Quiz): Sistema de perguntas e respostas com categorias, embaralhamento e justificativas didáticas.

🎥 Cinemateca: Galeria de mídias integrada para vídeos do YouTube e imagens.

🔐 Painel Administrativo: Interface restrita para criação, edição e exclusão (CRUD) de todo o conteúdo do portal.

🔍 Busca Global: Sistema de filtragem instantânea de posts e categorias.

📁 Estrutura do Código
Para facilitar o entendimento (estilo CursoemVideo), o código está dividido em:

Store (Estado): Onde os dados atuais da página ficam guardados enquanto você navega.

API: Funções que conversam diretamente com o Firebase.

UI & Views: Responsáveis por "desenhar" a tela sempre que algo muda.

Handlers: As funções que reagem aos seus cliques e digitações.

🚀 Como Visualizar
O projeto está hospedado diretamente no GitHub Pages, funcionando como uma página única sem necessidade de recarregamento.
